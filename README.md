# Пометка для первой части практической №3
## Расположение задач:
- Задача фибоначи: ветка pw3(fibonacci)
- Задача галактика: ветка pw3(galaxy)
- Задача буквы: ветка pw3(letters)

## Используемые способы отладки:
  1. Точка останова
  2. Панель инструментов отладки
  3. Элемент управления "Шаг с обходом"
  4. Элемент управления "Шаг в"
  5. Элемент управления "Шаг выхода"
  6. Элемент управления "Начать отладку"
  7. Элемент управления "Выполнить до щелчка"
  8. Окно "Автосодержимое"
  9. Окно "Локальные"
  10. Окно "Просмотр"
  11. Окно "Стек вызовов"
